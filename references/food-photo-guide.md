# 拍照记餐指南（视觉估重 + 记录规则）

## 工作流程
1. 用模型自身视觉识别菜品（不需要任何外部 API / 密钥，完全免费）。
2. 先向用户复述"我看到了什么、估了多少克"，允许纠正，再调用 `log`。
3. 能匹配内置库（食材 40+ / 中餐菜品 26 种）的用 `{"name","grams"}`，由脚本算宏量（source=db）；
   匹配不到的整菜（如"食堂红烧排骨"）由视觉直接估宏量，用 `{"name","kcal","p","c","f"}` 传入（source=vision-est）。
4. 每餐一次 `log`，每天一次 `summary` 核对目标；checkin 时用日志算平均摄入作为执行率证据。

## 份量视觉线索（常见中式餐具）
| 参照 | 估重 |
|---|---|
| 家用米饭一碗（平碗） | 150-200 g |
| 餐厅大碗面/粉（连汤带料整碗） | 400-600 g |
| 一盘炒蔬菜 | 200-300 g |
| 手掌大小的肉/鱼排（不含手指） | 100-120 g |
| 一块红烧肉/排骨 | 40-60 g |
| 一个饺子 | 25 g；一个肉包 80-100 g；一个馒头 100 g |
| 一个鸡蛋 | 50 g |
| 一听可乐 330 ml | 330 g；一瓶 500 ml | 500 g |
| 一杯珍珠奶茶（中杯） | 500 g |
| 披萨一片（12 寸切 8 块） | 110-130 g |
| 汉堡一个 | 200-250 g |

## 估重原则
- 宁可报区间（"米饭约 180 g"）也不装精确；用户纠正后以用户为准。
- 混合菜（盖饭/麻辣香锅）按可见主料拆分：主食 + 蛋白 + 蔬菜分别估。
- 油脂看不见但热量高：炒菜默认含油 8-10 g/盘，油炸食物脂肪上浮 50%。
- 照片只有一角或遮挡严重时，明确告知"看不清的部分我按 X 估"，或请用户补描述。
