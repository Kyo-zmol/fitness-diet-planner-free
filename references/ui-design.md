# UI 设计规范（v2，2026-09）

预览页与展示物料遵循从 [taste-skill](https://github.com/Leonxlnx/taste-skill)（84k⭐）与
[impeccable](https://github.com/pbakaus/impeccable)（65k⭐）提炼的设计语言：

## 设计读法（Design Read）
"开发者向健身技能的产品规格海报：运动编辑风（athletic editorial），
深炭绿底 + 单色荧光绿（volt #C6F24E）点缀，不对称 5/7 双栏，账本式数据行。"

## 遵守
- 左对齐超大黑体标题（letter-spacing -0.03em），标题自己说话，**不加 eyebrow/kicker**
- 数据用**账本行**（dashed 分隔、tabular-nums 右对齐），不用等大指标卡
- 单一 authored 视觉焦点（hero 照片 + 荧光绿强调词）
- 阴影带偏移+柔化；组内紧凑、组间宽松；标题上距大于下距
- 对比度 ≥4.5:1；代码块用等宽字体展示安装命令（开发者信任感）

## 禁止（anti-slop）
- 渐变文字标题、AI 紫渐变、居中 hero + 深色网格背景
- 三张等大 feature 卡、嵌套卡片、玻璃拟态装饰
- Inter + slate-900 默认组合；散落的多处入场动画
